# Frontend (React + Vite)

Ovo je **web** aplikacija, ne mobilna Expo app.

## Pokretanje

```bash
npm install
npm run dev
```

Otvori u pregledniku: **http://localhost:5173**

Backend mora raditi u drugom terminalu:

```bash
cd ../backend_app
npm run dev
```

**Ne koristi** `npx expo` — to ne pokreće ovaj projekt.
